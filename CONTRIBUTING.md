# Contributing

Thank you for your interest in AutoApplier.

## This repository

**AutoApplier-Public** contains documentation, roadmap, and results only. There is no application source code here.

- Open **Issues** for bugs, ideas, and feature requests
- Open **Discussions** (if enabled) for architecture feedback

## Code contributions

Implementation is maintained in a **private repository**. If you are a collaborator with access, follow the private repo's branch strategy (`develop` → `main`).

## What helps without code access

- Document typos and clarity improvements (PRs welcome here)
- Share anonymized benchmark ideas for RESULTS.md
- Competitive landscape notes (see README comparison table)

## Code of conduct

Be respectful and constructive. Do not post API keys, resumes, or personal data in Issues.
